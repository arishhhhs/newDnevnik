# Mood Diary — дневник настроения

Мобильное приложение на JavaScript, React Native и Expo.

## Что реализовано
- Приветственный экран, регистрация и вход (демо-авторизация без сервера).
- Главная страница с приветствием и последними записями.
- Выбор одного из пяти настроений, заголовок, заметка и теги.
- Просмотр подробностей записи.
- История, календарь и статистика настроений.
- Профиль и настройки.
- Локальное сохранение профиля и записей через AsyncStorage.

## Запуск в VS Code
1. Установи Node.js LTS.
2. Распакуй проект и открой папку `MoodDiary` в VS Code.
3. Открой терминал в VS Code.
4. Выполни:

```bash
npm install
npx expo start
```

5. Для запуска на Android Emulator нажми `a` в терминале Expo или выполни:

```bash
npm run android
```

## Запуск через Android Studio
1. Установи Android Studio и Android SDK.
2. В Android Studio открой **Device Manager** и создай виртуальное устройство (например, Pixel).
3. Запусти эмулятор.
4. В терминале проекта выполни `npx expo start`, затем нажми `a`.

> Это Expo-приложение: исходники редактируются в VS Code, а Android Studio используется для запуска Android-эмулятора. Открывать папку проекта как обычный Android Gradle-проект не требуется.

## Важно
Авторизация демонстрационная: серверной проверки пароля и облачной учётной записи пока нет. Данные хранятся локально на устройстве. Для реального выпуска приложения нужно добавить backend, безопасную авторизацию и политику конфиденциальности.
